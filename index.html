运行说明

双击 index.html，在 Chrome / Edge 等现代浏览器中即可运行，无需安装依赖、无需后端服务器。

部分浏览器会拦截 file:// 协议下的 fetch 请求，导致 data.json 无法加载。 此时在本目录打开命令行，任选一种方式启动静态服务器：
  • Python：python -m http.server 8000
  • Node.js：npx serve .
然后在浏览器访问 http://localhost:8000。

git clone <仓库地址> → 进入 integration 目录 → 按方式一或方式二运行。
